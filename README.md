# FIXON Partner Materials: R8

49 rynków krajowych i osobna oferta WARSAW HOME. Katalog obejmuje 73 produkty; ceny źródłowe pochodzą z 19 października 2026. Źródła dostawy oraz ich ograniczenia pozostają jawnie opisane w cennikach. Data wdrożenia nie jest datą nowego odświeżenia sklepu.

Progi programu zależą od wartości towarów netto przed rabatem. Maszyny oraz URBANROOT stanowią osobne kategorie. Szczegółowe warunki, wyjątki testowe i targowe oraz ograniczenia marży podano w programie i cennikach. Marża nie jest utożsamiana z rabatem.

Katalogi samodzielne w `client-files` są bezstratnie spakowane i sprawdzają zgodność danych przed otwarciem. Działają offline w aktualnych przeglądarkach. Lokalny plik `client-files/.gitattributes` chroni je przed konwersją końców wierszy; nie zastępuje reguł całego repozytorium.

Publikacja korzysta z GitHub Actions i kontrolowanego folderu wynikowego, nie z bezpośredniego wysłania całego repozytorium. Workflow sprawdza limit rozmiaru, nie publikuje ukrytych plików konfiguracyjnych i zachowuje samodzielne SVG drukarskie w repozytorium. Spis reklam odsyła do ich wersji w konkretnym commicie; internetowe PNG i katalogi PDF pozostają w Pages.

`release.json` identyfikuje wydanie, ale sam w sobie nie dowodzi wdrożenia. Nie uruchamiano wysyłki maili ani WhatsApp. Wzory umów PL/EN wymagają uzupełnienia danych i oceny właściwego prawa przed podpisaniem.
