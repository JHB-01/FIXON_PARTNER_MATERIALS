# FIXON R5 — aktualizacja GitHub Pages

Pakiet R5 jest aktualizacją przyrostową i zakłada, że wdrożone są już wcześniejsze aktualizacje R2, R3 oraz R4. Zawiera zmienione katalogi, cenniki i materiały informacyjne oraz 15 nowych zdjęć produktów. Nie zawiera ponownie niezmienionych plików współdzielonych z R3.

## Wdrożenie

1. Rozpakuj ZIP i skopiuj **całą jego zawartość** do głównego katalogu repozytorium strony, bez tworzenia dodatkowego katalogu nadrzędnego.
2. Zezwól na zastąpienie plików o tych samych ścieżkach. Nie usuwaj innych plików repozytorium.
3. Sprawdź zmiany w GitHub Desktop, zatwierdź je i wypchnij do GitHub zgodnie ze zwykłą procedurą publikacji.
4. Po wdrożeniu sprawdź stronę główną oraz wybrane katalogi, cenniki i materiały.

Nie zmieniaj ani nie usuwaj plików `.git`. Pakiet nie wykonuje zatwierdzenia ani publikacji.

## Ważne informacje

- Ceny sklepu odzwierciedlają stan źródeł z 19 października 2026 r. Archiwalny szacunek taryf przewozowych nie jest nową ofertą przewoźnika. Koszt dostawy wymagający potwierdzenia należy wyceniać indywidualnie.
- Nowe materiały zachowują wcześniej zatwierdzone zasady eksportu. Nie należy traktować nieweryfikowanych nowych filmów TikTok jako potwierdzonych; zachowano istniejące odnośniki, a zweryfikowane odnośniki YouTube są opisane oddzielnie.
- Zniżka WARSAW HOME 25% dotyczy wyłącznie wariantu zamówienia próbnego na to wydarzenie. Nie zmienia standardowej zasady zamówienia próbnego ani kalkulatorów krajowych.
- Cztery katalogi PDF są udostępniane w `downloads/fairs/`; odnośniki znajdują się w `downloads/index.html`.
- Wdrożenie i wypchnięcie zmian wykonuje użytkownik w GitHub Desktop.
- Pliki w `client-files/` są kopiami z wbudowanymi zdjęciami. Zachowują wcześniejsze ograniczenie: ich nawigacja do innych dokumentów nie działa poza strukturą rynku. Do publikacji i przeglądania całej oferty używaj stron w `markets/`.
