# Uruchomienie na GitHub Pages

## Najprostsza publikacja

1. Utwórz puste repozytorium na GitHub.
2. Wgraj do głównego katalogu repozytorium całą zawartość tej paczki, łącznie z folderem `.github`.
3. W GitHub otwórz **Settings > Pages**.
4. W sekcji **Build and deployment** wybierz **Source: GitHub Actions**.
5. Po wgraniu plików automatyczne wdrożenie pojawi się w zakładce **Actions**.
6. Po zakończeniu wdrożenia adres strony będzie widoczny w **Settings > Pages**.

## Aktualizacja

Przy kolejnej wersji zastąp zawartość repozytorium nową paczką i zatwierdź zmiany. GitHub ponownie opublikuje stronę automatycznie.

## Kontrola przed wysyłką

Otwórz stronę główną, wybierz rynek i sprawdź pięć pozycji na dolnym pasku: landing, Commercial Offer, Marketing Pack, cennik i katalog kwalifikacyjny.
