# FIXON European price lists

GitHub Pages-ready package generated on 2026-09-19.

- Upload the contents of this directory to a GitHub repository.
- Enable GitHub Pages for the repository root.
- Open `index.html` to choose one of 49 markets.
- Every country file is standalone: logo, CSS, JavaScript and 68 optimized product images are embedded.
- International settlements are in EUR; local-currency values are informational and rounded up to whole units.
